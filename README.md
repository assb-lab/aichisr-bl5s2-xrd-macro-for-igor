# aichisr-bl5s2-xrd-macro-for-igor

あいちシンクロトロン光センター BL5S2 で測定した粉末 XRD データ（Pilatus 自動積算のテキスト出力）を、Igor Pro 8 で一覧・プロットするための GUI 付きマクロです。

- **XRD Profile Viewer** — フォルダ内の XRD テキストを一覧表示し、選択したプロファイルを色分けして重ね描きします。
- **XRD 2D Map** — 温度変化測定などの連続スキャンを、2D マップ（image）と縦オフセット付きプロファイルで表示します。

## 必要なもの

- Igor Pro 8 以降（8.04 で動作確認）
- BL5S2 の Pilatus 自動積算で出力されたテキストファイル

## 対応するデータ形式

- 文字コード UTF-8、`#` で始まるヘッダ行に続いて、タブ区切り 3 列（2θ / 強度 / 標準偏差）が並ぶテキスト
- ファイル名は `<YYYYMMDDhhmmss>-<試料名>-<連番>.txt`
- 同じフォルダにある `*_Log.txt` は一覧に出しません

ファイル名の試料名を「シリーズ」、連番を「スキャン番号」、タイムスタンプを経過時間として使います。ファイル名がこの形式でなくても Profile Viewer では読み込めます。

## 導入

### エイリアスを張る（macOS）

リポジトリを clone し、付属のスクリプトで `Igor Procedures` フォルダにシンボリックリンクを作ります。Igor を再起動するとメニューバーに `AichiSR` が出ます。

```sh
./install_igor_alias.sh        # Igor Pro 8 に登録
./install_igor_alias.sh 10     # Igor Pro 10 に登録
./install_igor_alias.sh -u     # 登録を解除（リンクだけを消します）
```

リンク先は `~/Documents/WaveMetrics/Igor Pro <バージョン> User Files/Igor Procedures/` です。リンクなので、`git pull` すれば Igor 側も最新になります。

### 手動で読み込む

`AichiSR_BL5S2_XRD.ipf` を Igor Pro で開いてコンパイルするか、上記の `Igor Procedures` フォルダにコピーしてください。

## 使い方

### XRD Profile Viewer

メニュー `AichiSR` → `XRD Profile Viewer` で、左にファイル一覧、右にグラフが開きます。

1. `Open Folder...` でテキストの入ったフォルダを選びます。
2. 一覧でファイルを選ぶと、右のグラフに表示されます。Shift で範囲選択、Command で個別に追加・解除できます。
3. `Display` で見た目を調整します。

| 項目 | 内容 |
| --- | --- |
| `Filter` | ファイル名に含まれる文字で一覧を絞り込みます。`*` をワイルドカードとして使えます。 |
| `Colors` / `Reverse` | 色分けに使うカラーテーブルと、その向き。一覧の順に色が割り当てられます。 |
| `Offset / %` | トレース間の縦オフセット。表示中の最大強度に対する % で指定します。 |
| `Normalize` | 各プロファイルを最大値で規格化します。 |
| `Log intensity` | 縦軸を対数にします。 |
| `Legend` | 凡例の表示。凡例には `<試料名>-<連番>` を出します。 |
| `Autoscale` | 拡大した軸を全体表示に戻します。 |
| `2D Map...` | 同じフォルダを引き継いで 2D Map を開きます。 |

ファイルは選択したときに初めて読み込み、以後は読み込み済みのものを使います。ファイルが更新されていれば読み直します。

### XRD 2D Map

メニュー `AichiSR` → `XRD 2D Map (temperature series)` で開きます。

1. `Open Folder...` でフォルダを選びます。
2. `Series` で試料名を選びます。フォルダ内でファイル数が最も多い試料が最初に選ばれます。
3. 一覧でマップに使うスキャンを選びます（最初は全選択）。
4. `Build Map` を押すと、2D マップと縦オフセット付きプロファイルの 2 つのグラフが開きます。

スキャンごとに 2θ の開始点が違っていても、共通の 2θ グリッドに載せ直します。データのない領域は空白になります。

#### Y 軸

測定テキストには温度が記録されていないため、縦軸は次の 4 通りから選びます。

| 選択肢 | 内容 |
| --- | --- |
| `Scan number` | ファイル名の連番 |
| `Elapsed time / min` | ファイル名のタイムスタンプから求めた、最初のスキャンからの経過時間 |
| `Temperature (start + step)` | `Start` と `Step` から等間隔に温度を割り当てます |
| `Temperature (table)` | `Edit table...` で開く表の `T_user` に、スキャンごとの温度を入力します |

温度の単位は K と °C を選べます。昇温のあと降温するなど、温度が単調でない場合、image の縦軸はスキャンの順番になります（プロファイル側の色とラベルは入力した温度のままです）。

#### 表示の調整

| 項目 | 内容 |
| --- | --- |
| `2θ from` / `to` / `Full` | 両方のグラフの 2θ 範囲。`Full` で全域に戻します。 |
| Image: `Colors` / `Reverse` | マップのカラーテーブルと向き |
| Image: `Log colors` | 強度を対数でカラーに割り当てます。 |
| Image: `Auto Z range` / `Z min` / `Z max` | カラーの範囲。自動のときは、指定した 2θ 範囲内の最小・最大を使います。数値を入れると自動が外れます。 |
| Stacked profiles: `Colors` / `Reverse` | プロファイルの色分け。Y 軸の値に応じて色が付き、カラースケールが出ます。 |
| Stacked profiles: `Offset / %` | 隣り合うプロファイルの縦オフセット。2θ 範囲内の最大強度に対する % で指定します。 |
| Stacked profiles: `Every N` | N 本おきに間引いて表示します。 |
| Stacked profiles: `Label profiles` | 各プロファイルの右端に Y 軸の値（温度など）を書きます。 |
| `Show profiles` | プロファイルのグラフを閉じてしまったときに開き直します。 |

## グラフの体裁

X 線回折図形のグラフは次の体裁で作ります。

- 表示倍率 2 倍（`expand=2`）
- フォントサイズ 12、軸ラベルは 16
- tick は内向き、右と上にミラー
- 縦軸は axis only（目盛りの数値を出さない）
- 単位は括弧ではなく `/` で区切る（`2θ / deg.`、`Intensity / a.u.`）

体裁はグラフに最初のトレースが入ったときに適用します。そのあと手で変えた設定は、選択を変えても保たれます。

## データの格納場所

読み込んだデータは、カレントのエクスペリメントの次の場所に置かれます。ほかの解析にそのまま使えます。

| 場所 | 内容 |
| --- | --- |
| `root:AichiXRD:profiles:<名前>` | 強度。2θ が等間隔なら X スケーリング付き |
| `root:AichiXRD:profiles:<名前>_tth` | 2θ |
| `root:AichiXRD:profiles:<名前>_esd` | 標準偏差 |
| `root:AichiXRD:map:xrdMap` | 2D マップ（行 = 2θ、列 = スキャン） |
| `root:AichiXRD:map:scanLabel` ほか | 各スキャンのファイル名・連番・経過時間・入力した温度 |

`<名前>` は、ファイル名からタイムスタンプを除き、Igor の名前に使えない文字を `_` に置き換えたものです（例: `SampleA-12.txt` → `SampleA_12`）。

## 測定データについて

このリポジトリに測定データは含めていません。`.gitignore` で `TXT/` と、読み込んだデータを含みうる Igor のファイル（`*.pxp`、`*.ibw` など）を除外しています。
